# Quickstart: Marketplace Alignment

**Feature**: 005-marketplace-alignment
**Audience**: Maintainer about to cut the v0.2.0 release and submit upstream
**Time**: 30 minutes (excluding upstream PR review wait)

## Prerequisites

- Windows + PowerShell 5.1 / 7.x; `git` ≥ 2.30
- Spec Kit 0.8.10 installed (per `.specify/init-options.json`)
- All feature 002 + 004 outputs landed (parity-check, validation-pass, audit-install-state, 15+ tests green)
- GitHub repo with releases enabled and a fork of `github/spec-kit`

## 1. Verify required files

```powershell
Test-Path LICENSE
Test-Path CHANGELOG.md
Test-Path README.md
Test-Path README.zh-CN.md
Test-Path marketplace\catalog-entry.json
Test-Path marketplace\extensions-readme-row.md
Test-Path marketplace\upstream-pr-body.md
```

All True.

## 2. Run submission checklist

```powershell
.\.specify\extensions\speckit-superpowers-bridge\scripts\powershell\submission-checklist.ps1
```

Expected: 8 checks pass, exit 0.

## 3. Run cleanup audit

```powershell
.\.specify\extensions\speckit-superpowers-bridge\scripts\powershell\cleanup-audit.ps1
```

Expected: 0 P0/P1 findings.

## 4. Verify README parity

```powershell
.\.specify\extensions\speckit-superpowers-bridge\scripts\powershell\check-readme-bilingual-parity.ps1
```

Expected: `README parity: passed`, exit 0.

## 5. Verify bridge baseline still green

```powershell
.\.specify\extensions\speckit-superpowers-bridge\scripts\powershell\parity-check.ps1 -Strict
.\.specify\extensions\speckit-superpowers-bridge\scripts\powershell\validation-pass.ps1
.\.specify\extensions\speckit-superpowers-bridge\scripts\powershell\test-bridge-guard.ps1
foreach ($t in (Get-ChildItem tests\test-*.ps1)) { & $t.FullName }
```

All exit 0; every test ends `<suite>-tests-ok`.

## 6. Inspect catalog entry

```powershell
Get-Content marketplace\catalog-entry.json | ConvertFrom-Json | Format-List
```

Manual check: `id` correct, `tags` is exactly the 6-tag set, `description` ≤ 200 chars, `download_url` is a real release ZIP URL.

## 7. Verify trust badges render

Open the README on github.com; confirm all 4 badges render with valid data.

## 8. Walk the release runbook

Open `docs/release-runbook.md`; follow steps 1–12; honor every `Verify:` line.

## 9. Submit upstream PR

After runbook step 11, paste `marketplace/upstream-pr-body.md` into the PR description. AI-disclosure paragraph must be visible. Submit.

## 10. Monitor

Automated checks: minutes. Manual review: days to weeks. If asked for changes, fix in source repo first.

## Troubleshooting

| Symptom | Likely cause | Fix |
|---|---|---|
| `download_url_unreachable` | Release ZIP not yet built | Wait 2–5 min; re-run |
| `tags_mismatch` | Tags edited without CHANGELOG entry | Restore set OR document change |
| `manifest_path_inconsistency` | New file not in `includes`/`excludes` | Edit `plugin-distribution-manifest.yml` |
| README parity fails | Anchor drift between languages | Keep identical H2 anchors in both files |
| Upstream maintainer requests changes | Our checks didn't catch it | Extend `submission-checklist.ps1` |
