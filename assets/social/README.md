# Social Cards

Generated launch cards for README, GitHub, marketplace, Product Hunt, and
community posts.

| File | Size | Use |
|---|---:|---|
| `github-social-preview.png` | 1280x640 | README hero and GitHub repository social preview |
| `opengraph-card.png` | 1200x630 | OpenGraph shares, Dev.to, LinkedIn, and community links |
| `product-hunt-gallery.png` | 1270x760 | Product Hunt/gallery-style launch posts |
| `community-square.png` | 1080x1080 | Square thumbnails for X, Reddit, Discord, and WeChat-style posts |

These are final platform-sized PNGs generated with imagegen and then resized or
cropped to the target dimensions.
